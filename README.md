# 📱 Screen Time Tracker

A privacy-focused Android app that helps users understand and reduce their phone usage by tracking screen time, monitoring weekly progress, building daily habits, and providing motivational reminders.

## ✨ Features

- 📊 **Screen Time Monitoring** — View daily phone usage using Android usage statistics.
- 📉 **Weekly Progress** — Compare this week's screen time with the previous week.
- ⏱️ **Time Saved** — See how much screen time you have reduced over time.
- 📅 **Habit Calendar** — Manually mark successful days with a simple daily check-in.
- 📝 **Daily Notes** — Add a personal note for each day.
- 🎯 **Daily Goal** — Set a target for maximum daily screen time.
- 🔔 **Long-Usage Reminders** — Get a motivational reminder after extended phone usage.
- 💬 **Motivational Messages** — Encouraging messages when screen usage becomes high.
- 🌙 **Light & Dark Themes** — Switch between light, dark, and system theme modes.
- ⚙️ **Settings** — Manage goals, reminders, theme, permissions, and app preferences.
- 🔒 **Privacy First** — Designed to keep personal tracking data on the device without requiring an online account.

## 🔐 Usage Access Permission

To read screen-time statistics, Android requires the user to manually grant **Usage Access** permission.

Open:

**Settings → Apps → Special app access → Usage access**

Then enable access for **Screen Time Tracker**.

The exact menu names can vary depending on the Android device manufacturer and Android version.

## 📈 How It Works

The app focuses on improvement rather than simply showing a usage number:

**Track → Compare → Reduce → Check In → Reflect → Improve**

For example:

> You used your phone for **4h 20m today**  
> Your target is **5h**  
> You are **40m below your target** ✅

The weekly view can then show the change compared with the previous week.

## 📅 Habit Tracking

Users can manually check off days in the calendar when they successfully meet their personal screen-time goal.

Each day can also contain a short note, such as:

> "Studied for 2 hours without checking social media."

## 🔔 Motivation

When phone usage stays high for a configured period, the app can provide a gentle reminder such as:

> **Take a break 🌱**  
> You've been on your phone for a while. Put the phone down for a few minutes.
